# Безопасность

## Секреты

Не добавляйте в репозиторий OAuth-токены, webhook URL, API-ключи, пароли, cookies и файлы `.env`. Для локального запуска используйте переменные окружения или защищённое хранилище секретов.

## Внешние действия

Навыки для Яндекс Директа и Bitrix24 содержат примеры API-запросов. По умолчанию используйте только чтение и аудит. Перед изменением кампаний, ставок, бюджетов, сделок, контактов или CRM-полей необходимо отдельное подтверждение пользователя.

## Сторонний код

Скрипты скопированы из репозиториев, указанных в `PROVENANCE.json`. Они не запускаются при установке и не должны запускаться автоматически. Перед первым запуском проверьте команду, входные данные, сетевые адреса и ожидаемые изменения.

## Сообщение о проблеме

Если найден подозрительный скрипт, битая зависимость или утечка секрета, не запускайте файл. Зафиксируйте путь и upstream-коммит из `PROVENANCE.json`, затем удалите секрет из истории Git и отзовите соответствующий токен.
