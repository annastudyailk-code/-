**2026-06-27**: Research baseline — platform docs, REST API v2 (`https://api.instantly.ai/api/v2`, Bearer token with scopes, cursor pagination `starting_after`+`limit`, OpenAPI spec at `api.instantly.ai/openapi/api_v2.json`), webhooks, pricing, and affiliate program captured from live sources on this date. Key facts: **API v2 is fully incompatible with v1** (new key required; v1 deprecated). **API access is on all Email Outreach plans**; Unibox is Hyper-Growth+; webhooks reportedly need a higher tier (verify). Endpoints: campaigns, leads, lead-lists, accounts (email inboxes), analytics, emails, inbox-placement-tests, webhooks, api-keys, + subsequences/labels/tags/block-list/email-verification/workspaces. Webhook events: email_sent/opened/clicked/bounced, reply_received, lead_unsubscribed, status updates (meeting booked / not interested); configure in Settings → Integrations → Webhooks; implement retries+idempotency yourself. **Warmup is free on all plans**; **Lead Finder (Credits) and CRM are SEPARATE paid products** — real stack cost is well above the $47 Growth headline (~$118/mo Growth+Credits+CRM).
