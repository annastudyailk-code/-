**2026-03-25**: Research baseline (from git history) — platform docs were captured on/around this date and the API surface, pricing, and webhooks have NOT been re-verified against live docs since. Re-verify specifics before relying on them.
**2026-06-13**: API re-verified against live official docs — material drift fixed: People Search API path is `/mixed_people/api_search` (does NOT consume credits, never returns emails/phones; param `q_organization_domains_list`; `contact_email_status` values now verified/unverified/likely to engage/unavailable); Org Search is `/mixed_companies/search`; both capped at 50,000 records (100/page × 500 pages), not 100 pages/10k. Deals use `/opportunities` + `/opportunity_stages` (param `opportunity_stage_id`; create requires a MASTER API key → 403 otherwise). Calls use `/phone_calls`, `/phone_calls/search`, `/phone_calls/{id}`. People Match gained `webhook_url` (REQUIRED when `reveal_phone_number=true`, async return), `hashed_email`, `id`, `run_waterfall_email/phone`. Bulk Org Enrichment now takes a `details` array (≤10). Mobile phone reveal ≈8 credits (≈8× email). Usage/rate-limit stats endpoint is `POST /usage_stats/api_usage_stats` (master key; per-endpoint day/hour/minute with limit/consumed/left_over), replacing the unverified `POST /usage` shape. OAuth: authorize `https://app.apollo.io/#/oauth/authorize`, token `https://app.apollo.io/api/v1/oauth/token`, scopes ARE granular (contacts_search, person_read, opportunity_write; auto read_user_profile + app_scopes). Auth header canonical casing `X-Api-Key`; test key via GET /v1/auth/health. Pricing (2026): Free / Basic $49 annual ($59 mo) / Professional $79 ($99) / Organization $119 ($149) per user; credits expire each cycle, no rollover.
