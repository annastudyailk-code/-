**2026-04-15**: Research baseline (from git history) — platform docs were captured on/around this date and the API surface, pricing, and webhooks have NOT been re-verified against live docs since. Re-verify specifics before relying on them.
**2026-06-13**: API re-verified against live official docs — corrected drift: API rate limits are now tier-specific (private apps 100/10s + 250K/day Free/Starter, 190/10s + 625K/day Pro, 190/10s + 1M/day Enterprise; public OAuth apps 110/10s; "200,000/day" was stale), added CRM Search API limit (5 req/s account-wide, 200/page), API Limit Increase add-on (250/10s, max 2 packs), and webhook v3 signing (X-HubSpot-Signature-v3 + X-HubSpot-Request-Timestamp, HMAC-SHA256 over method+URI+body+timestamp, reject >5min); confirmed date-versioned API 2026-03 GA (breaking changes Mar/Sep, 18-month support, immutable); SDKs are Node.js/PHP/Python/Ruby (no separate JS or Go client). Pricing: Marketing Hub Starter now $9/seat/mo annual ($10 monthly) and Sales Hub Starter $9/seat/mo annual ($15 monthly) — both were listed at $20; Sales Pro $90/seat annual ($100 monthly); Marketing Pro $800 annual ($890 monthly); Free tier capped at 2 users / 1,000 contacts (was "unlimited"). Pro/Enterprise base prices, onboarding fees, and Content/Data/Service Hub pricing unchanged. Sources: https://developers.hubspot.com/docs/developer-tooling/platform/usage-guidelines, https://developers.hubspot.com/docs/apps/developer-platform/build-apps/authentication/overview, https://developers.hubspot.com/changelog/introducing-version-3-of-webhook-signatures, https://developers.hubspot.com/changelog/spring-2026-spotlight, https://blog.hubspot.com/marketing/hubspot-marketing-hub-pricing, https://blog.hubspot.com/sales/hubspot-sales-hub-pricing, https://developers.hubspot.com/docs/api/client-libraries.
