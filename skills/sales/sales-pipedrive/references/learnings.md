**2026-06-27**: Research baseline — platform docs, REST API v1+v2 (`{company}.pipedrive.com/api/{v1,v2}`, `x-api-token` header on v2 / `?api_token=` on v1 / OAuth 2.0 for Marketplace apps), webhooks, rate-limit model, pricing, and affiliate program captured from live sources on this date. Re-verify before relying. Key facts: **v1 full shutdown 2026-07-31** (v1 deprecation started 2026-01-01) — use v2 (cursor pagination via `limit`+`cursor`, `PATCH` for updates, ~50% cheaper tokens); Leads/Notes/Webhooks/Files/Filters/Goals/Projects are still **v1-only**. **Token-based rate limits**: daily budget = 30,000 × plan multiplier (Lite 1× / Growth 2× / Premium 5× / Ultimate 7×) × seats; 429 on exhaustion; per-user burst limit on a rolling 2s window; **webhooks are free (no token cost)**. **Custom fields are 40-char hash keys** (get the hash→label map from `*Fields` endpoints). Webhooks: `action.object` events; v2 payload `{meta, data:{current, previous}}`; retries at 3/30/150s; 10 first-attempt fails → 30-min ban; **3 days no success → webhook auto-deleted**. Response envelope `{success, data, additional_data}`. API + webhooks available on ALL plans (not gated) — only the token budget scales. Plan names changed late-2025: Lite/Growth/Premium/Ultimate (was Essential/Advanced/Professional/Power/Enterprise). GitHub org `pipedrive` (34 public repos). OpenAPI 3 specs published for v1 and v2; no official MCP server found. Affiliate: tiered 20%/30%/custom rev-share (first 12 months), 90-day cookie, PartnerStack-managed.
