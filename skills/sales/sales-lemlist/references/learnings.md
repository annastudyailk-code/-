**2026-03-28**: Research baseline (from git history) — platform docs were captured on/around this date and the API surface, pricing, and webhooks have NOT been re-verified against live docs since. Re-verify specifics before relying on them.
**2026-06-13**: API re-verified against live official docs — auth is BASIC-only (docs say verbatim "We use BASIC authentication NOT bearer"); removed the incorrect Bearer-token method. Rate limit unchanged at 20 req/2s but added documented response headers (X-RateLimit-Limit/Remaining/Reset, Retry-After). Webhooks: replaced "event types not fully documented" with the full ~80-event categorized list (email/LinkedIn/WhatsApp/SMS/call/lead-state/system) plus create params (targetUrl/type/secret/campaignId/isFirst/zapId) and the shared-`secret` verification model (NO HMAC). Pricing restructured: plans are now Email $39/user/mo ($31 annual) / Multichannel $109/user/mo ($87 annual, POPULAR) / Enterprise custom — old "Email Pro $69 / Multichannel Expert $99 / Outreach Scale" names retired; both paid tiers include 5 senders/user; database is 650M+ (was 600M+); WhatsApp add-on $20/seat/mo unchanged; SMS confirmed as a native channel. The legacy ~$9/additional-sender line is no longer shown on the pricing page — left in as unverified. Sources: https://developer.lemlist.com/api-reference/getting-started/authentication, https://developer.lemlist.com/api-reference/getting-started/rate-limits, https://developer.lemlist.com/api-reference/objects-definitions/webhook, https://developer.lemlist.com/api-reference/endpoints/webhooks/add-webhook, https://www.lemlist.com/pricing.
